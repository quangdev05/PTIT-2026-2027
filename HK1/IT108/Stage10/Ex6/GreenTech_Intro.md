- **Phát triển bền vững:** Tối ưu hóa năng lượng và giảm thiểu chi phí vận hành.

## 🔄 3. QUY TRÌNH LÀM VIỆC NHÓM VỚI GIT & MARKDOWN

Để tránh gặp lỗi xung đột file (Conflict), tất cả thành viên tuân thủ nghiêm ngặt 4 bước sau:

```bash
# Bước 1: Lấy dữ liệu mới nhất từ GitHub về máy trước khi sửa
git pull origin main

# Bước 2: Chỉnh sửa tài liệu Markdown (.md) trên máy cục bộ

# Bước 3: Đóng gói và lưu vết thay đổi
git add GreenTech_Intro.md
git commit -m "Docs: Cập nhật mục tiêu và phân công nhiệm vụ nhóm"

# Bước 4: Đẩy thay đổi lên GitHub
git push origin main
```
