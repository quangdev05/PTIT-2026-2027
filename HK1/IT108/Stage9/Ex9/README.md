# CLB LẬP TRÌNH PTIT - IT CLUB

Chào mừng bạn đến với **trang Wiki chính thức** của **CLB Lập trình PTIT**! Đây là nơi lưu trữ toàn bộ tài liệu kỹ thuật, hướng dẫn dành cho thành viên và các quy định chung của CLB.

## 1. Giới thiệu CLB

CLB Lập trình PTIT là **môi trường học tập chủ động**, nơi kết nối các bạn sinh viên có niềm đam mê với **lập trình, thuật toán và phát triển phần mềm**.

- **Slogan:** _Lập trình từ trái tim_
- **Điểm nổi bật:** Tổ chức **pitching dự án hàng tháng**, hỗ trợ **mentorship 1-1** cho tân sinh viên và luyện thi các giải đấu **Lập trình sinh viên ICD/ICPC**.

## 3. Hướng dẫn Gia nhập CLB

Thành viên mới vui lòng thực hiện tuần tự theo các bước sau để thiết lập môi trường làm việc:

1. **Tạo tài khoản GitHub** và cập nhật đầy đủ thông tin cá nhân (Họ tên, Mã sinh viên).
2. **Clone kho tài liệu của CLB** về máy cục bộ bằng lệnh Git:
   ```git
   git clone <URL_KHO_TAI_LIEU_CLB>
   cd wiki-docs
   ```
3. **Tạo nhánh riêng** để thực hiện bài test gia nhập:
   ```git
   git checkout -b feature/onboarding-pasv
   ```
4. **Tạo Pull Request (PR)** gửi lên nhánh `main` để Ban Kỹ thuật review bài làm.
